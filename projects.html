SIDE PROJECT • LIVE APP v1.0 • Google Gemma 2

SkillLens AI — Gemma-Powered Teaching Pack Generator

An open-source AI toolkit built for independent educators, private tutors, and coaching centers. It automates the preparation of high-quality teaching materials by transforming raw textbook excerpts and syllabus notes into ready-to-teach curriculum packs—saving teachers 5 to 12 hours of unpaid prep time every week.

  • Processes syllabus notes and PDFs to generate tiered diagnostic quizzes complete with verified explanations for both correct answers and distractors.
  • Outputs step-by-step worked math exercises with KaTeX mathematical formatting and spaced-retention study flashcards.
  • Features an interactive Socratic assistant drawer that coaches students through misconceptions rather than spoiling direct answers.
  • Built with Google's Gemma 2 open model family, supporting both cloud inference (Google GenAI SDK) and 100% private offline local generation via Ollama.

HireLens — Smart Resume Screener

An AI-powered resume analysis engine that parses and ranks applicant resumes against job descriptions using NLP techniques. Helps recruiters filter high volumes of applications with semantic similarity scoring and automated keyword extraction.

  • Uses TF-IDF and sentence embeddings to rank candidates objectively against job description criteria.

ReviewNest — Mom's Verdict Generator

An AI-driven product review synthesizer built for the Mumzworld platform. Aggregates customer reviews and uses Google's Gemini LLM to generate a "Mom's Verdict" — a parent-friendly summary of what real moms are saying about a product.

  • FastAPI backend with Gemini LLM integration for review synthesis and sentiment categorization.
  • React/Vite frontend deployed on Vercel; resilient backend deployed on Render.
  • Aggregates sentiment, confidence scores, and key buyer insights from hundreds of reviews.
  • Implements robust JSON parsing and retry logic for dependable LLM output.

SIDE PROJECT • COMPLETE v2.0

SignScribe Pro — Real-Time ASL Hand Gesture Translator

Real-time American Sign Language (ASL) to text and speech converter running entirely in the client's browser. Uses MediaPipe hand-tracking with a geometric gesture classifier to eliminate server latency and protect user camera privacy.

  • Achieved 94% accuracy across 26 ASL gesture classes under real-world webcam conditions.
  • Browser-native pipeline using MediaPipe + WebGL for instant, zero-latency inference.
  • Stabilized gesture smoothing to prevent flickering predictions.
  • Includes a sentence builder with integrated Text-to-Speech output.
JavaScript MediaPipe WebGL OpenCV Python
